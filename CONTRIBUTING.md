# Contributing to tylomon

Thanks for your interest in tylomon. Bug reports, feature ideas, documentation fixes and code are all welcome.

The full guide is in the documentation:

- **[Contributing](https://brpaz.github.io/tylomon/development/contributing/)**: how to report bugs, request features and report security issues; the development process from branch to release; and the code style
- **[Development Setup](https://brpaz.github.io/tylomon/development/setup/)**: environment, Task commands, tests and git hooks

The same pages are in this repository under [`docs/development/`](docs/development/).

In short: open an issue first for anything bigger than a small fix, use [Conventional Commits](https://www.conventionalcommits.org/), run `task ci` before opening a pull request against `main`, and update the docs along with the code. tylomon is largely written with AI coding assistants (see the [README](README.md)); AI-assisted contributions are fine, and you remain responsible for what you submit. Contributions are released under the [MIT license](LICENSE).
